# 默认文章排版

改善文章的阅读结构，不改变作者的论点。按以下三个阶段处理。

## 1. 先诊断

编辑前通读完整标题与正文，识别：

- 开头、核心观点、话题转折、例子与结尾；
- 包含多个完整意思的大段连续文字；
- 混合了不同话题的段落，以及本应合并的零散片段；
- 真正的章节标签、并列项、步骤与引用内容。

不要把格式变化误判为主题变化。已捕获的文章标题只作为上下文，不要在正文中重复生成。

## 2. 再重整

只做足以让文章清楚易读的必要调整。

1. **优先处理段落。** 每段只承载一个主要意思。在话题切换、举例、对比、结果或过渡处拆段；
   将共同表达一个意思的意外碎片合并。只要存在清楚的段落边界，就不能让全文继续保持为一整块长文本。
2. **只为真正的章节使用标题。** 保留现有标题并修正混乱的层级。较长文章在存在明确章节边界但缺少标题时，
   可以补充简短、中性的标题，并优先使用原文已有词语。不要把短文切得过碎，不要把普通句子提升为标题，
   不要重复文章标题，也不要创建下方只有一个无实质短段落的标题。
3. **只在语义成立时使用结构。** 真正并列的项目可转为无序列表，连续步骤可转为有序列表；
   只有真实引用内容才使用块引用。不要创建单项列表，也不要把普通宣传文案变成引用。
4. **克制使用强调。** 保留有意义的粗体与斜体。只有在确实有助于浏览时，才给少量关键词或结论添加强调；
   不要强调整段文字，也不要把每一节都装饰一遍。
5. **轻量润色。** 修正明显的标点、空白与段落边界问题。仅在重整结构后确有必要时，
   微调衔接或措辞。不要虚构观点、例子、数据、摘要或行动号召，也不要改变作者立场与语气。

## 3. 最后核验

返回结构化文档前，确认：

- 每个段落都有连贯作用，全文不再存在可以明确拆分的大段连续文字；
- 标题和列表确实改善了导航，而不是只增加装饰；
- 正文内容没有无故丢失、重复或改变顺序；
- 所有链接目标和图片均保留、未被修改、相对顺序一致，图片属性完整；
- 结果符合调用方要求的文档与输出约束。

只返回调用方要求的结构化文档。只有原文已经通过以上质量检查时，才可以原样返回。
