description: Improve editorial structure and readability while preserving the article's intent, links, and images.
---

Format the supplied publication for clear editorial reading.

1. Preserve the article's subject, intent, facts, and voice. You may make
   restrained wording, punctuation, whitespace, and transition edits that
   improve readability.
2. Preserve every link target and image, including image attributes and
   relative position. Linked text may move with the surrounding edit.
3. Normalize paragraph boundaries and whitespace where it improves structure.
4. Apply heading levels only to text that already functions as a heading.
   Maintain a coherent hierarchy without promoting ordinary prose.
5. Use lists and blockquotes only when the existing content already expresses
   list or quotation structure.
6. Use bold and italic sparingly to preserve or clarify existing emphasis.
   Avoid decorative styling that changes the article's meaning.
7. Return only the structured document requested by the caller. Verify that
   the article's meaning, links, and images remain intact before finishing.
